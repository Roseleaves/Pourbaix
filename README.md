# Pourbaix 图互动演示（pourbaix4）

打开 `index.html` 即可使用，无需构建或本地服务器。

## 文件

- `index.html` — 页面、布局与静光紫色主题
- `data.js` — 物种 ΔGf°、酸碱家族、配体、环境物料、六个预设
- `chem.js` — 参考态分解与配平、E°/logK、A/B/C 三模式平衡、相图采样
- `app.js` — Canvas 渲染、交互、图例、反应面板、PNG 保存
- `tests.html` — 化学层自检；浏览器打开应显示 **ALL PASS · 48 checks**

## 功能

- 主元素 → 价态/归类筛选 → 物种勾选；带配体的物种可先选，自动启用所需物料
- A（优势相）/ B（1:1 叠色）/ C（真实平衡混色）三模式，默认 C
- 六个预设：铁锈蚀、铝两性、锰竞争、氯常温、氮亚硝酸–氨、硫亚硫酸–硫代硫酸
- 主元素含 Zn（银与铅之间）；Zn 可查看单质、氧化物、Zn(OH)₂、锌酸盐、
  氨/氰/氯配合物，以及菱锌矿 ZnCO₃、闪锌矿 ZnS；其他金属也补充了菱镁矿、
  菱铁矿、白铅矿、方铅矿等常见难溶成矿物
- 环境物料：酸碱、配体/沉淀剂（合并）、氧化还原；只保留一个「筛选物料」按钮，未启用分组自动隐藏
- 横轴为横条选项：pH / lg[Cl⁻] / lg[NH₃]。非 pH 横轴时，酸碱分组出现
  OH⁻ 固定 pH 控件；pH 模式不显示 OH⁻。切到 lg[Cl⁻] 自动勾选含氯沉淀/配合物，
  lg[NH₃] 自动勾选氨配合物，pH 模式自动勾选难溶氢氧化物
- 主元素总浓度 C_tot 移到化学环境，与配体浓度一起调；范围至 56 M，
  1 M / 0.01 M / 10⁻⁵ M 三处磁吸（不再放三个按钮）
- 相区标签按整块相区居中；相界线悬停整段高亮；稳定相界反应显示实际 pH/E 与标准 pKa/E°/logK
- 配色：固有 / 随机；随机每次点击重新分配，相邻相区色相尽量远离；图例色块可自定义单色，
  相图填色与图例同步刷新
- 正文写法 / 纯文本消歧 / 图例写法三个下拉；正文写法作用于物种表、反应式与悬停
- C 模式气体按分压着色（N₂、NO、NO₂ 等无溶解前体的气体也能显示）；水稳定线、
  介质 pKa/电对线；静光主题；保存 PNG
- 环境弹窗底部：清空物料与物种 / 启用常用物料（Cl⁻、CO₃²⁻、NH₃）/ 完成

## 数据与近似

- 25 °C，理想溶液（活度≈浓度；纯固体/纯水 a=1）；NBS 1982 为主来源。
- 配合物/部分沉淀的 ΔGf° 由 logβ/Ksp 自洽推得，物种行标注「推得」。
- Al(OH)₃ 采用三水铝石（gibbsite）值；铁预设采用 Fe(OH)₃ 作为锈蚀初期相，
  FeO(OH)/Fe₂O₃ 可在物种列表手动勾选。
- 多聚钒酸根、部分硫物种未细分；HNO₂ 的 pKa 采用 NBS 导出值（约 2.4，
  文献约 3.1–3.3，属数据源差异）。
- 锌矿物取常见近似值：ZnCO₃（菱锌矿，log Ksp≈−10.0）、ZnS（闪锌矿，≈−24.7）、
  ZnO（锌华）；Zn(OH)₂ 取活性/无定形值。氧不再作为主元素，仅保留 H₂O/OH⁻/O₂
  等溶剂与参考物种。
- 气体逸出用 Henry + 死体积/氩气稀释近似；C 模式中无溶解前体的气体
  （N₂、NO、NO₂ 等）由主元素化学势反算平衡分压，再按 p/P_env 着色。
  不含动力学/过电位。
